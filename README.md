# Разбор тарелки — тестовый сайт на Vercel

Страница: фото + ответы на 6 вопросов → разбор по промпту бота (`prompt.md`).
Каждый разбор — отдельный запрос к API (GPT или Claude) без истории: 1 промпт, 1 ответ.

## Как устроено
Модель не пишет текст ответа. Она только классифицирует тарелку по правилам и возвращает JSON (статусы пунктов и названия продуктов). Текст собирает код из готовых фраз — поэтому модель не может переписать формулировки, добавить оговорки или сломать формат.

## Файлы
- `index.html` — страница в виде диалога: фото → «что в тарелке» → кнопки (приём пищи, напиток, масло, сытость) → разбор.
- `СЦЕНАРИЙ_БОТА.md` — тот же диалог для разработчика сейлбота.
- `api/analyze.js` — серверная функция: отправляет фото и ответы модели, получает JSON, собирает текст.
- `lib/compose.js` — **готовые фразы ответа**. Хотите поменять формулировку, итог, призыв, шапку — правьте здесь.
- `prompt.md` — **правила оценки** для модели (что красное, что жёлтое, справочник продуктов). Хотите поменять логику оценки — правьте здесь.
- `vercel.json`, `package.json` — настройки для Vercel, не трогать.

## Переменные окружения (Vercel → Settings → Environment Variables)
Сайт работает либо через OpenAI (GPT), либо через Claude. Если задан `OPENAI_API_KEY` — используется GPT.

| Имя | Обязательно | Что это |
|---|---|---|
| `OPENAI_API_KEY` | для GPT | Ключ с platform.openai.com → API keys |
| `ANTHROPIC_API_KEY` | для Claude | Ключ с console.anthropic.com (не нужен, если задан OPENAI_API_KEY) |
| `ACCESS_CODE` | очень желательно | Код, который тестировщики вводят на странице. Без него любой, у кого есть ссылка, тратит ваши деньги на API |
| `MODEL` | для GPT — да | Модель: для GPT — та, что стоит в вашем боте (название из platform.openai.com → Models); для Claude по умолчанию `claude-sonnet-5-5` |
| `WEBINAR_LINK` | нет | Ссылка на вебинар в призыве. По умолчанию `[ссылка]` |
| `WEBINAR_DATES` | нет | Даты практикума в призыве. По умолчанию «18 и 19 ноября в 19:00 по Москве» |
| `PRACTICUM_NAME` | нет | Название в предложном падеже. По умолчанию «бесплатном практикуме по гастриту, изжоге и вздутию» |
| `HEADER` | нет | Первая строка разбора. По умолчанию «Разбор по системе врача-гастроэнтеролога Ольги Валерьевны» |
| `TEMPERATURE` | нет | `0` — ответы стабильнее от прогона к прогону |

## Как обновить правила или фразы
GitHub → репозиторий → `prompt.md` (правила) или `lib/compose.js` (фразы) → карандаш (Edit) → изменить → Commit changes.
Vercel сам пересоберёт сайт примерно за минуту.
